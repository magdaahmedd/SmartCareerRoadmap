# Smart Career Roadmap

Smart Career Roadmap is a beginner-friendly Python GUI application that helps programming students choose a career path and follow a clear learning roadmap.

The application analyzes the user's current skills, identifies the skills they need to learn, and provides learning resources and a mini project for each skill.


## Project Idea

Many beginners don't know:

- Which programming career path to choose.
- What skills they should learn.
- Which skill they should start with.
- Which resources they can use to learn.
- What projects they can build while learning.

Smart Career Roadmap helps solve this problem by providing an organized learning roadmap based on the user's selected career and current skills.


## Features

- Choose a career path.
- Select the skills you already know.
- Analyze your current skills.
- Identify the next skill to learn.
- Calculate your learning progress.
- Display learning resources for each skill.
- Suggest a mini project for each skill.
- Save your progress.
- Continue your previous progress.
- Display a completion message when all skills are completed.
